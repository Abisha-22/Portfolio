# Where to put your photos

Drop your image files in this folder using these exact names, and they'll
appear automatically (the site falls back to clean placeholders until then):

| File name | Used for |
|---|---|
| `profile.jpg` | Your photo on the Home and About pages |
| `fruit-ripeness-predictor.jpg` | Demo image on the "ML-Based Fruit Ripeness & Spoilage Predictor" project page |
| `smart-bin-waste-segregation.jpg` | Demo image on the "Smart Bin" project page |
| `iot-smart-irrigation.jpg` | Demo image on the "IoT-Based Smart Irrigation System" project page |
| `plc-bag-scanning.jpg` | Demo image on the "PLC Bag Scanning" project page |

Recommended sizes:
- `profile.jpg` — square, at least 400×400px
- Project images — landscape, roughly 1600×800px (16:8), screenshots, device
  photos, or short demo GIFs (rename `.gif` and update the `src` in
  `src/pages/ProjectDetail.jsx` if you use a GIF)

No editing needed elsewhere — just add the files with these names.
